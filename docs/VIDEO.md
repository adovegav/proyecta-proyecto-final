# Guion del video

Duración orientativa: 10–15 minutos, ajustable a lo que indique el docente. No se especificó duración obligatoria.

1. Presentación: objetivo, React + API REST, dos proyectos y relación proyecto/tareas.
2. Mostrar repositorio GitHub, ramas y commits. Mostrar carpetas y archivos de ejemplo sin exponer secretos.
3. Desde una copia limpia: verificar Node/Git, instalar paquetes backend y frontend con `npm ci`, copiar y configurar `.env`, inicializar SQLite y crear usuario con los comandos que se implementen.
4. Iniciar ambos procesos; explicar puertos, CORS y URL de API.
5. Pantalla 1, login: mostrar error de contraseña y autenticación correcta.
6. Pantalla 2, dashboard: explicar contadores obtenidos desde API.
7. Pantalla 3, lista de proyectos: mostrar lista y acceso al formulario.
8. Pantalla 4, formulario proyecto: crear, volver a lista, editar y verificar cambios.
9. Pantalla 5, lista de tareas: mostrar relación con proyecto.
10. Pantalla 6, formulario tarea: crear con proyecto, editar estado y comprobar lista/dashboard.
11. Mostrar eliminación de proyecto con tareas rechazada; borrar tarea y luego proyecto. Mostrar confirmación de borrado.
12. Verificar persistencia reiniciando backend y demostrar 401 sin token con cliente REST o terminal.
13. Mostrar vista móvil, guía y entregables finales.

Preparar datos pequeños y legibles. Abrir pestaña Network para evidenciar Fetch y los métodos REST. Mantener texto legible y audio claro. No mostrar el token, contraseñas reales ni JWT_SECRET. Revisar que el video o su enlace pueda abrirse antes de entregar.
