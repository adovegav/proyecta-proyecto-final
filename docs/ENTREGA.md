Aplicación: gestor de proyectos y tareas, con seis pantallas, dos CRUD relacionados, API REST protegida por JWT, PostgreSQL 18 y diseño responsivo React.

Historial: ramas `main`, `develop` y `feature/base-proyecto`; más de diez commits lógicos. La aplicación se ejecuta localmente siguiendo la guía. El enlace de GitHub es del código, no una aplicación alojada públicamente.

Validación: diez pruebas de integración aprobadas; prueba de interfaz de seis pantallas, ambos CRUD y vista móvil; instalación de los ZIP extraídos, build y persistencia tras reinicio comprobados.

Video: MP4 H.264, 1280 × 900, duración 3:18. Incluye instalación real en copia limpia y demostración con explicaciones escritas en español; sin voz. Las credenciales de la base y el secreto JWT no se incluyen en los ZIP ni en Git.
